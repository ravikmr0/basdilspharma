# BASDILS PHARMA - Premium Pharmaceutical Website

## Project Overview

A premium, modern, and professional pharmaceutical company website for **BASDILS PHARMACEUTICALS PVT. LTD**, designed to reflect trust, innovation, healthcare excellence, and scientific research with global pharmaceutical standards.

## Website Features

### 🎨 Design Highlights
- **Premium Clean Design** with modern pharmaceutical aesthetic
- **Responsive Layout** optimized for mobile, tablet, and desktop
- **Advanced Animations** including scroll animations, parallax effects, and smooth transitions
- **Glassmorphism Effects** with soft shadows and elegant styling
- **Professional Typography** using Poppins and Inter fonts
- **SEO Optimized** structure with schema markup and meta tags

### 🏢 Core Brand Colors
- **Primary Blue**: #0B3D91 (Deep Medical Blue)
- **Secondary Green**: #00A86B (Pharma Green)
- **Accent Cyan**: #12B5CB (Premium Cyan/Teal)
- **Background**: White with Light Grey sections
- **Text**: Dark Charcoal (#1A1A1A)

### 📄 Website Pages

1. **Home (index.html)** - Main landing page with all key sections
2. **About Us (about.html)** - Company history, mission, vision, leadership
3. **Products (products.html)** - Complete product portfolio and details
4. **Manufacturing (manufacturing.html)** - Facility showcase and certifications
5. **Contact (contact.html)** - Multiple contact options and inquiry forms

### 🛠️ Technical Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Fonts**: Google Fonts (Poppins, Inter)
- **Icons**: Font Awesome 6.4.0
- **Animation Library**: CSS Animations & Transitions
- **Responsive Framework**: CSS Grid & Flexbox
- **Performance**: Optimized loading and lazy loading ready

## Installation & Usage

### Basic Setup
This is a pure HTML/CSS/JavaScript website. You can open the HTML files directly, or use the npm-based local dev workflow below for a proper local server.

### Local Testing
1. Clone or download the project
2. Install dependencies with `npm install`
3. Start the local server with `npm run dev`
4. Open the local URL shown in the terminal

### Direct Browser Preview
1. Open `index.html` in a web browser
2. Navigate through the website using the menu

### Customization

#### Update Company Information
- Edit contact details in `contact.html` and footer sections
- Update phone numbers and email addresses
- Change office address and map location

#### Modify Colors
Edit the CSS variables in `css/styles.css`:
```css
:root {
  --primary-blue: #0B3D91;
  --secondary-green: #00A86B;
  --accent-cyan: #12B5CB;
  /* ... other variables */
}
```

#### Add Images
Place images in `assets/images/` and reference them:
```html
<img src="assets/images/your-image.jpg" alt="Description">
```

#### Update Products
Edit product cards in `products.html` to add your actual products.

### Form Integration
To connect forms to an email service:
1. Update form IDs and fields as needed
2. Integrate with a backend service or email API
3. Update `js/main.js` form submission handlers
